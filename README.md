# Playwright com Python

Projeto criado para estudo e prática de automação de testes utilizando Playwright com Python.

O objetivo deste repositório é consolidar os conhecimentos adquiridos durante o aprendizado da ferramenta, explorando desde a configuração do ambiente até a criação e execução de testes automatizados para aplicações web.

Durante os estudos estão sendo abordados temas como:

- Criação de testes automatizados com Playwright
- Utilização do Pytest para execução dos testes
- Localização de elementos (locators)
- Execução em diferentes navegadores
- Emulação de dispositivos e alteração de viewport
- Organização de uma estrutura de automação
- Boas práticas de automação de testes
- Geração de relatórios e evidências

## Tecnologias

- Python
- Playwright
- Pytest
